Robot = microservicio distribuido

Todo robot sigue el mismo patrón de 3 capas. Tú ya lo conoces con otro nombre.

Percepción · Sensores
Leer el mundo: distancias, IMU, cámara, LiDAR
→ Input / API endpoint
Procesamiento · CPU
Tomar decisiones con base en los datos
→ Lógica de negocio / microservicio
Acción · Actuadores
Mover motores, articulaciones, ruedas
→ Output / efecto en el sistema

Stack tecnológico del capstone

ROS2 es a la robótica lo que Docker es a DevOps: middleware de comunicación. Los nodos son microservicios; los tópicos, un bus de eventos.

ROS2comunicación→ Gazebosimulación→ SLAMmapeo→ Nav2navegación→ RVizvisualización
